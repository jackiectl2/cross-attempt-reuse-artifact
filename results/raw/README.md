# Raw tables behind every reported number

`raw_manifest.json` lists every file below with its bundle path, its source path in the cluster project directory,
size, row count and columns, plus the parser metadata (13,482 runs; 151,293 tool calls; 76,213 query_db calls;
30 runs without tool calls; recomputed labels pass 4,543 / fail 8,939 / validator error 0; DAB revision
f6b1ad07a61da2077ae7e074416900dbb452d1bc). It is generated by `code/raw_manifest.py` on the cluster and covers the files copied from the cluster
work directory: the tables, the job scripts, the job logs and the task files of the submission tool (1,047 files).
It is not a listing of this directory: 34 further files here were written on the login node or on the authors'
machine and are outside it — this README, `raw_manifest.json` itself, `job_ledger.json`, `cluster_nodes.json` and
`cluster_nodes_scontrol.txt`, `dab_inputs.json`, the three files under `plan/`, and auxiliary files of the submission
tool and of early capacity tests under `logs/` (`cpu_batches/`, `cpu_batches_test*.tasks`, `cpu_queue/.lock`,
`cpu_queue/ledger`, three `cpu_queue/*.log` files, two `*.code.sha256` files, `insp2.py`, `write_ok_62966796`).
`MANIFEST.sha256` at the root of the archive lists every file of the archive, these included.

Aggregated outputs (JSON / CSV) live next to this directory under `results/` (analysis_dab_r3, ablate, live*, e2e,
e2e_trace, concurrent_live, xharness, reproduce, analysis_seed*; `analysis_dab_r1` and `*_certv1*` used the original
Contract B, `analysis_dab_r2` and `*_rules7*` its rules 1–7; see the provenance notes of the top-level README).

Rebuild the reported aggregates from these tables (CPU cluster; `envs/*.sif` as in `REMOTE-COMPUTE.md`):

```bash
# B0/B1/B2/B3 aggregates (reported run analysis_dab_r3; needs <v2>/p2_audit.json, a copy of results/p2_audit.json)
ED_REPLAY_DIR=<raw>/v2/replay_dab python code/analyze2.py <raw>/v2 <out> 200 200 16 results/live/costs.json
# robustness (newer libraries)
ED_REPLAY_DIR=<raw>/v2/replay python code/analyze2.py <raw>/v2 <out_m1> 200 200 16
# review-round analyses (thresholds, concentration sensitivity, online-E exposure, MongoDB fidelity)
ED_REPLAY_DIR=<raw>/v2/replay_dab python code/extra_analyses.py <raw>/v2 <out> <out>/extra_analyses.json 50 50 16
# ablations, concurrency, statistics, cross-harness
python code/sim_ablate.py run <raw>/v2 <out>/base_E.json base 50 16 E results/live3/costs.json
python code/concurrent_sim.py run <raw>/v2 <out>/concurrent.json 10 16
python code/stats_tests.py <analysis_dir> <out>/stats.json
python code/xharness.py analyze <raw>/xharness/calls.parquet <out>/results.json
# clean-room check against the reported outputs
python code/reproduce.py results results/analysis_dab_r3 <out>
```

`extra_analyses.py`, `sim_ablate.py` and `concurrent_sim.py` read `<v2>/live/costs.json`; copy `results/live/costs.json`
there first. `sim_ablate.py run` takes the clone cost of S2c from its last argument. Parquet files are excluded from git (`.gitignore`); they are the artifact payload.
